JETT

Agent JETT · 疾风代课

第 1 章 · 变量与数据类型

Jett 的身法很随性：一把刀、一团烟，说来就来。C 语言里的变量也差不多——它是一个小盒子，用来存东西，随存随取，还能随时改。血量掉一点，hp 就减一点，这就是变量存在的意义：帮程序记住需要记住的东西。

大白话：变量是带名字的盒子

声明一个变量，就是告诉 C："给我准备一个盒子，贴上名字 hp，里面放整数。"等你要用血量时，直接喊 hp 这个名字就行。盒子里装的东西随时能换——hp = hp - 30，就是把盒子里的数取出来减 30 再放回去。

为什么要有"类型"？

因为盒子得先定大小和装法。计算机底层全是 0 和 1，同一串二进制，按整数读是一个数，按字符读可能是个字母。类型就是告诉程序：这块空间有多宽、里面的 0/1 该怎么解读。新手先认识这三种：

  • int —— 整数，比如血量 100、击杀 18。占 4 字节左右，能装 ±21 亿以内
  • double —— 带小数，比如 KD 1.53、爆头率 63.5%。占 8 字节，更"宽敞"
  • char —— 一个字符，比如段位字母 'A'、结算结果 '胜'。占 1 字节

声明一句话：类型 名字;。想边声明边给值就叫"初始化"，比如：

#include <stdio.h>

int main() {
    int hp = 100;        // 声明 int 并初始化成 100
    double aim = 88.5;   // 枪法评分，带小数
    char rank = 'B';     // 注意：字符用单引号括起来

    printf("我的血量：%d\n", hp);
    printf("枪法评分：%f\n", aim);
    printf("段位：%c\n", rank);
    return 0;
}

眼尖的同学会发现 printf —— 别慌，它是 C 的"打印机"，输出用。这一章先当黑盒使，下一章 Brimstone 会把它讲透。

还有个细节得提：起名字有规矩。名字可以用字母、数字、下划线，但不能数字开头，也不能和关键字撞名（int、char 这些词被系统预定了）。kills、kd_ratio 都行，2kills、int 就不行。名字自己起，但得让人一眼看懂——没人想知道 a 到底是什么。

⚠ 新手常踩的坑

  • Int hp; —— 把 int 写大写。C 严格区分大小写，Int 不是类型，编译直接报错
  • char a = "A"; —— 单引号 '' 才是字符，双引号 "" 是字符串（好几个字符）。一个字符用单引号
  • int hp = "100"; —— 类型不匹配。整数变量只能装整数，不能塞字符串
  • 声明了变量却忘了初始化：int hp; 直接拿来用，里面的值是"上一任房客"留下的垃圾数字

划重点

  • 变量 = 带名字的盒子，先声明（int hp;）再用
  • 类型决定装法和空间：int 整数、double 小数、char 单字符
  • = 是"装进去"，不是数学里的"等于"
  • 字符用单引号 ''，C 区分大小写，名字不能数字开头

课后练习 · 纸上谈兵

  1. 看代码猜输出：int hp = 100; hp = hp - 30; printf("%d", hp); 屏幕上会显示多少？
  2. 下面哪个是合法的变量名？kills、2kills、int、kd_ratio
  3. 想存你的 KD 值 1.53，应该用什么类型？
  4. 脑筋急转弯：为什么计算机需要"类型"这种东西？
点开看答案 1. 70（血量先 100，减 30 变 70）。2. kills 和 kd_ratio。3. double。4. 因为同样的 0/1 按不同类型读出来完全不同，类型是"解读方式"。

char 只能存一个字符？想要一长串字、还带空格的那种？那是第六章数组的活儿，急什么。

BRIMSTONE

Agent BRIMSTONE · 指挥官代课

第 2 章 · 输入输出（printf / scanf）

Brimstone 是队里负责喊话的指挥官：他得接收指令，也得播报战报。一个 C 程序跟人打交道，干的就是这两件事：把话说出去，把话接进来。

printf：往外"播报"

printf 是 C 的打印机。它最神奇的地方是那个 %d——这叫格式说明符，相当于在句子留了个坑位。坑位后面跟的变量，会按顺序填进去：

#include <stdio.h>

int main() {
    int kills = 18;
    int deaths = 12;

    printf("本场 %d 杀 %d 死，KD 不错哦\n", kills, deaths);
    //      ^^^^      ^^^^
    //      第一个坑位填 kills，第二个坑位填 deaths
    return 0;
}

坑位有讲究，什么类型填什么符号，对不上就会打出垃圾值：

  • %d 整数 · %f 小数 · %c 单字符 · %s 字符串

结尾那个 \n 是"换行符"，它让你的光标在打完这行后另起一行——不然一屏幕字全糊成一条。

scanf：从键盘"接收"

scanf 负责读键盘输入。它和 printf 长得很像，但有个关键区别——scanf 要的是"地址"，所以变量前面必须加 &：

#include <stdio.h>

int main() {
    int kills;
    printf("请输入你的击杀数：");
    scanf("%d", &kills);      // 读一个整数，写进 kills 那个盒子

    printf("本场击杀了 %d 个敌人！\n", kills);
    return 0;
}

为什么 scanf 要 & 而 printf 不要？

区别在目的：printf 只需要"把这个值打印出来"，所以给它值就够了；scanf 要"改这个变量"，想改一个盒子，你必须先找到它住在哪，& 就是"取地址"的意思。现在先记牢"scanf 要带 &"，至于地址是什么、怎么用，第八章 Cypher 会把它彻底讲明白——你会在那里恍然大悟。

⚠ 新手常踩的坑

  • scanf("%d", kills) —— 忘了写 &。程序可能直接崩溃，或者往垃圾地址写值，这是 C 里最有名的翻车点之一
  • printf 里坑位数量和后面变量数量对不上 —— 少填了会打印垃圾数字，多填了会被忽略
  • %d 配了 double —— 类型对不上，打出来是乱码数字
  • 忘写 return 0; —— 编译器会嘀嘀咕咕警告你（虽然一般还能跑）

划重点

  • printf("文字 %d", 变量) —— 坑位按顺序填
  • 坑位对号入座：%d 整数、%f 小数、%c 字符、%s 字符串
  • scanf("%d", &kills) —— 记住要加 &，因为要改变量的地址
  • \n 是换行，让输出另起一行

课后练习 · 纸上谈兵

  1. 补全：scanf("%d", ____); 想读进变量 hp，空位该填什么？
  2. 想读一个小数进 double 变量，scanf 的坑位符号是什么？
  3. 思考：为什么 printf 不用 &，scanf 却要？
  4. 看代码猜输出：printf("%d-%d", 3, 5);
点开看答案 1. &hp。2. 小数点用 %lf。3. 因为 scanf 要"改"这个变量，必须找到它的地址；printf 只要值。4. 3-5。

学完这章，你就能写一个"报击杀数"的小程序了。虽然它只会反过来问你话，但程序问你话哎，多酷。

PHOENIX

Agent PHOENIX · 火焰代课

第 3 章 · 运算符

Phoenix 的技能讲究连招：点火 → 灼烧 → 回血，一套下来伤害拉满。运算也是把数据"连"起来的东西，让它们互相加减乘除，算出一个新值。

算术运算符全家桶

运算符意思例子
+加5 + 2 得 7
-减5 - 2 得 3
*乘5 * 2 得 10
/除（整数相除只留整数部分）5 / 2 得 2
%取余（除完剩多少）5 % 2 得 1
++自增（自己加 1）i++ 等价 i = i + 1
--自减（自己减 1）i-- 等价 i = i - 1
=赋值（把右边装进左边）a = 5
+= -= *= /=算完再赋值a += 3 等价 a = a + 3

运算顺序：跟数学一个规矩

先乘除后加减，括号最高优先——和小学学的一模一样，不用担心。真正要小心的坑在下面：

整数除法会"丢小数"

int / int，结果是 int，小数部分被无情丢掉。5 / 2 是 2，不是 2.5。想算 KD 这种精确除法，得先把其中一个强转成小数，强转的写法是 (double)：

#include <stdio.h>

int main() {
    int kills = 10;
    int deaths = 3;

    double kd = (double)kills / deaths;   // 强转成小数再除，才有精确结果
    double kd_wrong = kills / deaths;     // 整数除整数，结果是 3 然后塞进 double

    int money = 2500;
    money -= 800;        // 买把枪，剩 1700
    int spare = money % 1000;   // 算算一千以外的零头 = 700

    printf("正确 KD 是 %f\n", kd);        // 3.333333
    printf("偷懒的 KD 是 %f\n", kd_wrong); // 3.000000，看出来差距了吗
    printf("买完枪剩 %d\n", money);
    printf("零头 %d\n", spare);
    return 0;
}

取余 % 有什么用？

判断奇偶、算零头、做循环里的"每 N 次"——都是它的主场。n % 2 得 0 就是偶数，得 1 就是奇数。记住这个，练习会用到。

⚠ 新手常踩的坑

  • 5 / 2 想得 2.5 —— 两个整数相除丢小数，结果是 2。要精确就强转
  • a = a + 1 看成数学矛盾 —— 它是"把 a 取出来 +1 再放回去"，程序常态，别慌
  • 除以 0 —— a / 0 程序直接崩，C 不帮你拦
  • a *= 2 + 1 理解错 —— 它等价 a = a * (2+1)，乘法作用于右边整个式子

划重点

  • int / int 结果是整数，小数被丢掉
  • 想要精确除法，用 (double) 强转其中一个
  • % 取余：判断奇偶、算零头一把好手
  • ++ -- 自增自减；+= -= 是简写
  • 运算顺序：先乘除后加减，括号最大

课后练习 · 纸上谈兵

  1. 心算：10 / 3 是多少？10 % 3 又是多少？
  2. 心算：5 + 3 * 2 等于几？（想想运算顺序）
  3. 把 money = money + 500 改写成复合赋值写法。
  4. 思考：怎么用一条运算判断一个整数是奇数还是偶数？
点开看答案 1. 3 和 1（整除剩 3，取余剩 1）。2. 11（先乘 3*2=6，再加 5）。3. money += 500。4. n % 2 == 0 是偶数，否则奇数。

看到 a = a + 1 千万别慌，它不是数学矛盾，是程序在给自己叠 buff。

SAGE

Agent SAGE · 哨卫代课

第 4 章 · 条件判断（if / switch）

Sage 从不乱奶：谁血低了才奶，谁倒了才拉。这叫按条件办事——程序里最最常见的套路。C 里想"看情况做不同的事"，就用 if 家族和 switch。

if / else if / else：一路问下去

if (条件) 括号里的条件如果成立（为真），就执行后面花括号里的代码；不成立，就跳到 else if 再问一次；全都不成立，走最后的 else。判断是从上往下"命中即停"的：

#include <stdio.h>

int main() {
    int hp = 25;

    if (hp <= 30) {
        printf("血量太低，Sage 奶你一口！\n");
    } else if (hp < 80) {
        printf("有点小伤，注意走位\n");
    } else {
        printf("满状态，冲！\n");
    }
    return 0;
}

条件里要用的比较运算符：== 等于、!= 不等于、> 大于、< 小于、>= 大于等于、<= 小于等于。想组合条件：&& 是"并且"，|| 是"或者"。

switch：多个具体值逐个对号

当判断的是"等于某一个具体值"、且情况很多时，switch 比一串 if 更清爽——比如按钱数决定这回合买什么枪：

int money = 4500;

switch (money / 1000) {   // 4500 / 1000 = 4
    case 0:  printf("经济局，别浪\n"); break;
    case 1:  printf("半起枪，打信息枪\n"); break;
    case 4:  printf("满甲大枪，随便打\n"); break;
    default: printf("钱多，全给安排上\n"); break;
}

每个 case 结尾那个 break 千万别省——它是"这一档处理完就收工"的出口。不写 break，程序会"贯穿"下去，把后面所有 case 的内容全执行一遍，这是 switch 最有名的陷阱。找不到匹配项时，走最后的 default。

⚠ 新手常踩的坑

  • if (hp = 100) —— 用了一个 =！这是赋值不是比较。赋值几乎总是"真"，分支永远成立。判断相等必须 ==
  • switch 里忘写 break —— 程序一路贯穿，把所有 case 都执行一遍
  • case 后面写变量 —— switch 的 case 只能跟常量，不能跟变量
  • 用 = 代替 == 在条件里比较数字，编译器顶多警告，跑起来全错

划重点

  • if (条件) { } else if { } else { } 从上往下，命中即停
  • 判断相等用 ==（两个等号！）
  • 组合条件：&& 并且、|| 或者
  • switch 适合"等于某个具体值"，每个分支结尾 break

课后练习 · 纸上谈兵

  1. 推演：上面 if 的例子里，hp = 50 会走哪个分支？打印什么？
  2. if (kills > 10 && deaths < 5) —— 什么时候这个条件才为真？
  3. switch 里忘写 break 会怎样？
  4. 找 bug：if (score = 100) 想判断 score 是不是 100，哪里写错了？
点开看答案 1. 走 else if（50 ≤ 30 不成立，但 50 < 80 成立），打印"有点小伤，注意走位"。2. 两个条件都满足才算数。3. 一路贯穿，后面的 case 全执行。4. 用了 = 应该是 ==。

== 才是相等，= 是赋值。这俩写错一个，报错能让你找一下午——学长的血泪教训，现在传给你了。

RAZE

Agent RAZE · 轰炸代课

第 5 章 · 循环（for / while）

Raze 的炮台会一直突突突，直到子弹打完。这就是循环：同一件事反复做，做到某个条件满足才停。C 里有两兄弟：

  • for —— 知道"要做几遍"，比如进攻方要打 12 个回合
  • while —— 看情况"做到什么时候"，比如子弹打到没

for：三件套，照着填

for (起点; 条件; 步进) 三个坑位分别是：从哪开始、做到什么时候停、每轮做完怎么变。执行顺序很关键：先初始化 → 判断条件 → 执行代码 → 步进 → 再判断 → …，直到条件不成立跳出。

#include <stdio.h>

int main() {
    // 进攻方打 12 个回合
    for (int round = 1; round <= 12; round++) {
        printf("第 %d 回合：冲点！\n", round);
    }

    // 子弹打到没为止
    int bullets = 5;
    while (bullets > 0) {
        printf("哒哒哒！还剩 %d 发\n", bullets - 1);
        bullets--;   // 打掉一发，否则永远打不完
    }
    return 0;
}

round++ 就是"每回合自己加 1"（还记得第三章的 ++ 吗）。想中途停手？break 能直接跳出循环——就像 Raze 自己看场面不对，提前收了炮台。

while：先问再做；还有个"先做再问"的弟弟

while (条件) 是先判断后执行：条件一开始就不成立，就一次都不做。它有个弟弟 do-while，先执行一次、再判断，至少会做一遍——适合"先开枪后看战绩"的场景。这一章不用背它，知道有这号人就行。

⚠ 新手常踩的坑

  • 死循环：条件永远成立，比如 while (1) 或者忘写 bullets--，程序转成无限炮台停不下来
  • 循环里忘了"改变步进"——循环变量一直不变，要么死循环要么跳不出
  • 想打 12 次却写 round <= 12 还是 round < 12 分不清 —— 一个执行 12 次，一个只执行 11 次（从 1 数到 11 是 11 个）
  • i++ 手滑写成 i--，计数方向反了，条件永远满足 → 死循环

划重点

  • for (起点; 条件; 步进) —— 初始化→判断→执行→步进，循环往复
  • while (条件) —— 先判断后执行，条件一开始不成立就一次都不做
  • break 中途跳出循环
  • 别让条件永远成立，那就是死循环

课后练习 · 纸上谈兵

  1. 推演：for (int i = 1; i <= 3; i++) 会执行几次？打印 i 依次是什么？
  2. 推演：while (bullets > 0)，如果一开始 bullets = 0，会执行几次？
  3. 想打印 1 到 5，for 的条件应该怎么写？
  4. 思考：为什么循环体里一定要有让条件"靠近结束"的动作（比如 i++）？
点开看答案 1. 3 次，i 依次是 1、2、3。2. 0 次（先判断，条件一开始就不成立）。3. for (int i = 1; i <= 5; i++)。4. 没有步进，条件永远不变，就会死循环。

死循环 = 你的程序变成炮台，子弹无限，停不下来。想让它停，只能手起刀落关窗口。

ARMORY

军械库 · 装备清点

第 6 章 · 数组与字符串

你见过弹夹吧？一发发子弹排成一串，整个弹夹就是一个数组——一堆同类型数据的排队。往弹夹里装 5 发子弹：

数组：连续的一排小格子

声明数组：int bullets[5] 意思是"给我一排 5 个 int 格子"。数组在内存里是挨着排的一排房间，每个房间有编号（下标），从 0 开始：

#include <stdio.h>

int main() {
    int bullets[5] = {1, 1, 1, 1, 1};  // 弹夹里 5 发子弹

    printf("第 1 发：%d\n", bullets[0]);  // 1
    printf("第 3 发：%d\n", bullets[2]);  // 1

    bullets[2] = 0;   // 第 3 发打出去了，变成 0（空）
    printf("打完第 3 发后：%d\n", bullets[2]);
    return 0;
}

全世界新手都踩的坑：下标从 0 开始

第 1 个元素是 bullets[0]，不是 bullets[1]。你数到第 5 发的时候，它是 bullets[4]。规律：第 N 个元素，下标是 N-1。为什么会这样？因为下标是"离第 1 格多远"——第 1 格离自己 0 格远，第 5 格离第 1 格 4 格远。

还有个大前提要强调：数组的长度在声明时就定死了，bullets[5] 永远 5 格，想扩容得换个新的。而且——C 不帮你检查下标越界。你写 bullets[7]，它不会拦你，只会读到内存里乱七八糟的别的数据，或者把别的数据写坏。这是 C 最著名的"野路子"。

字符串：就是字符数组，末尾藏着个 \0

"一长串文字"呢？比如你的游戏 ID？C 里的字符串本质就是一个字符数组，末尾还藏着个看不见的 \0（结束符），专门告诉 printf"这串字到这就结束了"：

char name[] = "Jett";   // 一串字符排成数组
// 内存里实际是：J e t t \0 （4 个字母 + 1 个结束符）
printf("我的 ID 是 %s\n", name);   // %s 打印整串字符串

所以 "Jett" 看着是 4 个字母，占的空间其实是 5 格——那格 \0 是必须的，没有它，程序不知道这串字在哪结束，会一直往后读。这就是为什么字符串长度要"多加 1"。上一章学的 %s 在 printf 里用的就是它。

⚠ 新手常踩的坑

  • 下标从 1 开始数 → 访问错元素，第一个元素永远是 arr[0]
  • 越界访问 bullets[5]（长度 5 的合法下标是 0~4）—— C 不拦你，读到垃圾数据或写坏内存
  • char name[4] = "Jett"; —— 忘了 \0 占一位，4 格装不下 5 个字符
  • 想用 == 比较两个字符串 —— 不行，== 比较的是地址不是内容。现在先别比较字符串，记住这个坑就行

划重点

  • 数组 = 一串同类型的值，类型 名字[数量]，长度声明后定死
  • 下标从 0 开始：第 1 个是 arr[0]，第 N 个是 arr[N-1]
  • C 不检查越界，访问要自己守规矩
  • 字符串 = char[]，末尾藏 \0，打印用 %s

课后练习 · 纸上谈兵

  1. int a[4] 的合法下标范围是多少到多少？
  2. 推演：char s[] = "AB"; 实际占几个 char？（想想 \0）
  3. bullets[0] 是弹夹里的第几发子弹？
  4. 思考：为什么字符串必须有 \0 这个结束符？
点开看答案 1. 0 到 3（共 4 个）。2. 3 个（A、B、\0）。3. 第 1 发。4. 让程序知道这串字符在哪结束，否则会一直往后读。

记住"从 0 数起"这一条，你的弹夹就不会少装一发、多耗一发。多少大神就是在数组边界上翻的车。

技能系统 · Q / E / C / X

第 7 章 · 函数

每个特工都有技能，每个技能就是一坨封装好的动作：按下 Q，它就执行一整套东西。C 里的函数就是这个——给一段代码起个名字，随时叫它来干活。这大概是 C 里性价比最高的发明：写一遍，用一万遍。

先定义（发明技能），再调用（使用技能）

函数长这样：返回值类型 函数名(参数) { 要执行的代码 }。看看一个"治疗"技能：

#include <stdio.h>

// 定义一个"治疗"技能，amount 是奶量（参数）
void heal(int amount) {
    printf("治疗了 %d 点血量！\n", amount);
}

int main() {
    heal(50);   // 调用技能，奶 50
    heal(30);   // 再调用一次，奶 30
    return 0;
}

函数名字前的 void 是"这个技能不回报结果"。如果它要算个数字还给你（比如算 KD），前面就写结果的类型——double kd()，函数里用 return 把结果递回去。

程序是怎么"执行"函数的？

想象指挥官喊"heal(50)"：程序先记下自己现在站在第几行（方便回头），然后"跳"进函数里把动作做完，做完再"跳"回刚才的地方接着往下走。所以函数的执行是：记位置 → 跳进去执行 → 跳回来继续。参数 amount 是调用时"喂"进去的东西——放技能要选目标，喂参数就是选数值。

为什么值得封装？

第一是复用：一段逻辑写一次，到处调用。第二是好改：以后要改"治疗"的逻辑，只改函数里一处，全程序生效——不用满世界找代码复制粘贴。你早就享受过这个福利了：printf 就是别人封装好的技能。

⚠ 新手常踩的坑

  • 函数开头忘写返回值类型（void 或别的）—— 编译报错
  • 有返回值的函数忘写 return —— 会返回一个垃圾值
  • 函数写在了 main 后面，调用处又看不到它 —— 会警告"隐式声明"。新手先养成"定义写在 main 前面"的习惯
  • 调用时参数类型和定义对不上 —— 比如函数要 int，你传个字符串

划重点

  • 函数 = 起名一段代码：返回值类型 函数名(参数)
  • 定义（发明）一次，调用（使用）无数次
  • void = 不返回值；有返回值用 return 结果;
  • 写代码先想"哪些动作反复用" → 塞进函数

课后练习 · 纸上谈兵

  1. 推演：调用 heal(50) 屏幕会打印什么？
  2. 想写一个"算出 KD 再还给你"的函数，返回值类型该写什么？
  3. void 是什么意思？什么时候用？
  4. 思考：为什么要把重复的代码塞进函数，而不是每处复制一遍？
点开看答案 1. "治疗了 50 点血量！"。2. double（KD 带小数）。3. 表示这个函数不返回值，只干活不递结果时用。4. 复用 + 好改：改一处全程序生效，不用满世界找。

你早就在用函数了——printf 就是别人封装好的技能。抄起别人的技能用，这叫"站在巨人的肩膀上"，不丢人。

第 8 章 · 指针

Cypher 不爱记情报本身，他记的是"情报放在哪个点位"——地图坐标。指针也一样：它不存值，存的是"值住在哪个地址"。指针是 C 的分水岭，也是这一整份教程的终点站，深呼吸，你完全能看懂。

把内存想成一排带门牌号的房间

每个变量都住在一个房间里，房间有门牌号（地址）。变量是"房间里的东西"，地址是"房间的门牌号"。指针就是一个专门记门牌号的变量：

#include <stdio.h>

int main() {
    int hp = 100;
    int *p = &hp;   // p 是一个指针，存的是 hp 的房间门牌号（地址）

    printf("hp 的值：%d\n", hp);            // 100
    printf("hp 的地址：%p\n", (void*)&hp);  // 一串地址（门牌号）
    printf("用指针读值：%d\n", *p);         // *p 顺着地址取出值 = 100

    *p = 50;   // 通过指针，改房间里存的东西
    printf("hp 现在变成了：%d\n", hp);      // 50
    return 0;
}

两个符号，一对搭档

  • int *p —— 声明"p 是一个存地址的变量"（别管那个 * 放哪，意思都是指针）
  • &hp —— 取 hp 的地址（门牌号）
  • *p —— 解引用，顺着门牌号进去，把房间里的值取出来（或改掉）

一句话：指针存的是"快递单号"，* 是"去取件"。快递单号本身不是包裹，但它能让你准确找到包裹。Cypher 的摄像头也一样——它指向情报，但不等于情报。

一个让全场恍然大悟的瞬间

还记得第二章 scanf 那个神秘的 & 吗？scanf("%d", &kills) 的意思现在揭晓了："把键盘读进来的整数，直接写进 kills 那个房间"——所以它要的是地址，不是值。你从第二章就被埋伏笔了，现在正式接上。

指针还有其他玩法（比如指向数组、指针加减），但那属于"进阶副本"。这一章你的目标很单纯：看得懂 & 和 * 在干嘛，就满分了。

⚠ 新手常踩的坑

  • 指针没初始化就 *p = 50 —— p 里的地址是垃圾，等于往随机房间乱改东西，可能直接崩
  • p = 50 —— 把整数当地址塞进指针，类型不匹配（指针只能存地址）
  • 搞混 &p 和 *p —— &p 是"指针变量自己的门牌号"，*p 才是顺着 p 去取东西
  • scanf 忘写 & —— 现在知道严重性了吧：没给地址，程序不知道该把值写进哪

划重点

  • 指针存的是地址，不是值本身
  • &变量 取地址；*指针 解引用取值/改值
  • scanf 带 &，因为要往那个变量的地址里写值
  • 这一章的目标：看得懂，会认。不要求手写复杂指针

课后练习 · 纸上谈兵

  1. 推演：int x = 5; int *p = &x; 那么 *p 是多少？
  2. 接着上题：执行 *p = 9; 之后，x 是多少？
  3. scanf("%d", &x) 里那个 & 为什么必需？
  4. 一句话总结：指针变量里存的到底是什么？
点开看答案 1. 5（顺着地址取出了 x 的值）。2. 9（指针改了房间里存的东西，x 跟着变）。3. 要往 x 的地址里写值，必须知道 x 住在哪。4. 存的是地址（门牌号），不是值本身。

指针劝退过一代又一代人。别怕，你就记一句话：指针是快递单号，* 是去取件。

综合实战 · 战绩结算

第 9 章 · 拼一张你的战绩结算卡

学了这么多，是时候串起来玩一把了。目标：让程序打印一张你自己的 VALORANT 战绩结算卡。它几乎用上了前面所有章节——变量存数据（第 1 章）、printf 排版（第 2 章）、运算符算 KD（第 3 章）、字符串存 ID（第 6 章）：

#include <stdio.h>

int main() {
    char name[]  = "你的游戏ID";   // 字符串（第 6 章）
    int kills    = 18;             // 击杀数（第 1 章）
    int deaths   = 12;             // 死亡数
    double kd    = (double)kills / deaths;  // KD：强转才精确（第 3 章）
    char win     = '胜';           // 本场结果

    printf("====================\n");
    printf("  VALORANT 战绩结算卡\n");
    printf("====================\n");
    printf("玩家ID  ：%s\n", name);
    printf("击杀数  ：%d\n", kills);
    printf("死亡数  ：%d\n", deaths);
    printf("KD 比值 ：%.2f\n", kd);
    printf("本场结果：%c\n", win);
    printf("====================\n");
    return 0;
}

这行 %.2f 是新的：意思是"小数保留 2 位"，卡片的 KD 就不会打出一长串 3.333333。数字换 1 就是 1 位小数，改着玩。

你不需要真的运行它——但请跟着代码走一遍，想象屏幕上打出来的样子。然后试这几个改动，看看"思考"的过程：

  • 把 kills 改大，KD 是不是变高了？（试试改成 30）
  • 把 name 换成你自己的 ID，卡片就是你的了
  • 把 '胜' 换成 '负'，看哪一行会变
  • 把 %.2f 改成 %.1f，KD 小数位少了一位

⚠ 这题最容易翻车的地方

  • 忘写 (double) 强转 —— 18 / 12 是整数 1，KD 直接变成 1.00，看着像假战绩
  • 坑位对不上 —— %s 配字符串、%c 配单字符、%d 配整数，写错就打印乱码
  • 忘写 \n —— 卡片内容全糊成一行，逼死强迫症

课后练习 · 挑战你的学长卡

  1. 给卡片加一行"爆头数"，用变量 int headshots 存 11，然后 printf 打印出来
  2. 用 if（第 4 章）加一行：胜负如果是 '胜' 打印"上分了"，否则打印"掉大分"
  3. 用 scanf（第 2 章）让玩家自己输入击杀数，再打印卡片
  4. 挑战：用 for 循环（第 5 章）打印一长排 =====，代替手动打一串
点开看答案（示意） 1. 加一行 int headshots = 11; 和 printf("爆头数 ：%d\n", headshots);。2. if (win == '胜') printf("上分了\n"); else printf("掉大分\n");。3. scanf("%d", &kills);。4. for (int i = 0; i < 20; i++) printf("=");。改完都可以发给学长检查！
